# Projeto Titã — Product Vision

## One-line vision

A local-first workout tracker for Web, PWA, Android, and iOS that works completely offline, supports optional sync, preserves data ownership, and offers optional AI-powered analysis for users who choose to connect their own provider.

## Product character

Projeto Titã should feel like a real product, not a coding demo.

It should be:

- responsive;
- fast;
- visually polished;
- simple for beginners;
- deep for advanced users;
- transparent about data;
- portable;
- open source.

## Product promise

The user does not need:

- an account;
- a cloud subscription;
- an API key;
- AI;
- constant internet access;

to have an excellent workout tracker.

Advanced users can opt into:

- advanced set logging;
- training methodologies;
- progression strategies;
- periodization;
- sync;
- AI analysis.

## Main differentiators

1. Local-first by default.
2. Offline-first.
3. Full Web/PWA + Android/iOS.
4. Optional cross-device sync.
5. Portable JSON/ZIP backups.
6. Advanced but optional training tracking.
7. Exercise demos with license-aware media providers.
8. Deterministic weekly/monthly analytics without AI.
9. Optional BYOK AI with explainable, read-only-first analysis.
10. Open-source and user-controlled data.

## UX principle

A beginner should be able to log:

`80 kg × 8`

without learning advanced training vocabulary.

An advanced user may optionally track:

- RPE/RIR;
- tempo;
- set type;
- mesocycle;
- progression strategy;
- rest behavior.

The advanced layer must not make the basic layer worse.
